# AI-Powered Insights Dashboard using Microsoft Fabric

## 📌 Overview
This project demonstrates how to build an AI-powered analytics solution using Power BI and Microsoft Fabric concepts.

It combines:
- Power BI dashboards
- AI-generated insights
- Data analytics workflows

---

## 🚀 Features
- Interactive Power BI dashboard
- AI-generated business insights
- Data-driven decision support
- Scalable architecture using Fabric concepts

---

## 🛠️ Tech Stack
- Power BI
- Python (Pandas)
- OpenAI API
- Microsoft Fabric (Lakehouse + Notebook concept)

---

## 📂 Project Structure
- data/ → Dataset
- notebook/ → AI insight generation
- powerbi/ → Dashboard file
- screenshots/ → Dashboard preview

---

## ▶️ How to Run

1. Clone repo
2. Install dependencies:
   pip install pandas openai

3. Add OpenAI API key
4. Run:
   python notebook/ai_insights.py
